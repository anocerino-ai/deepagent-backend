# S3 Backend

`S3Backend` stores files in S3-compatible object storage such as AWS S3 or Garage.

## Config

Use `S3Config` with:

- `bucket`
- `prefix`
- `region`
- `endpoint_url`
- `access_key_id`
- `secret_access_key`
- `use_ssl`

## Local development with Garage

The repository's `docker-compose.yml` starts Garage as its local S3-compatible service:

- Endpoint: `http://localhost:3900`
- Bucket: `test-bucket`
- Access key: `GK0123456789abcdef0123456789abcdef`
- Secret key: `0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef`

The low-level example uses these defaults. Override the secret key with
`GARAGE_SECRET_ACCESS_KEY` when running `examples/basic_usage.py`.

## Notes

- Virtual paths map to S3 keys under `{prefix}/...`.
- `awrite()` fails when the object already exists.
- `upload_files()` and `download_files()` operate on raw object bytes.
